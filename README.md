# LocalGo - Proyecto Base

## Estructura del Proyecto
- `backend/`: API REST en Node.js + Express.
- `database/`: Script SQL para PostgreSQL.
- `android/`: Clases de persistencia Room DB (Kotlin).

## Ejecución en VS Code
1. Abre la carpeta `backend/` en VS Code.
2. Copia `.env.example` a `.env` y configura la URL de PostgreSQL.
3. Ejecuta `npm install` y luego `npm run dev`.
